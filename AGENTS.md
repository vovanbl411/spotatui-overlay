# Сопровождение Spotatui Overlay

- Оверлей содержит `media-sound/spotatui` и готовит обновления по профилю
  Release. Принятое состояние находится в `main`. Применяйте
  [Gentoo Overlay Standard v0.2](https://github.com/vovanbl411/gentoo-overlay-standard/blob/15601aaac42493e30b80ce52b61a4a90f0446721/STANDARD.md).
  Принятие стандарта в центральном репозитории и принятие этого оверлея
  по S2 требуют отдельных решений владельца.
- Версии определяйте по ebuild. Храните текущую версию и предыдущую для
  отката. При ротации сохраняйте точное имя fallback вместе с `-rN`, если
  он есть. Пакет рассчитан на amd64 glibc, использует ALSA для Spotify,
  отключает Cargo default features и включает дополнительные возможности
  через USE. [Пользовательские команды и USE](README.md)
- Обычная ротация меняет ebuild и Manifest. Изменения USE, зависимостей,
  бэкенда, Rust minimum, лицензий и других условий упаковки требуют
  отдельного ревью. При остановке на Cargo-контракте разберите
  upstream diff и согласуйте упаковку.
- Сохраняйте связь тега с SHA и скачанным архивом, сверку базового архива
  с принятым Manifest, проверку crate по `Cargo.lock` и доверенный handoff.
  Prepare читает репозиторий. Publish создаёт только отсутствующий ref
  и Draft PR. При неполной или неопределённой публикации решение принимает
  владелец. [Путь кандидата](docs/AUTOMATION.md)
- Из корня репозитория выполните команды ниже. Тесты работают без сети,
  а сверка Manifest проверяет состав архивов crate локально. Repository CI
  запускается для PR в `main` и для push в `main`.

  ```sh
  PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s scripts -p 'test_*.py' -v
  python3 scripts/release_automation.py check-manifest --root .
  ```

- Держите изменения в согласованном объёме. Перед принятием владелец
  сверяет точный head, базу, diff, результаты CI и применимые проверки
  пакета, затем сливает PR вручную. Изменения GitHub settings и решение
  по S2 требуют отдельного согласования.
  [Приёмка и восстановление](docs/CI_AND_SECURITY.md)
